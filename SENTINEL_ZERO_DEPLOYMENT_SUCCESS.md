### 🚀 DÉPLOIEMENT PRODUCTION

#### Prérequis
- ✅ Docker et Docker Compose installés
- ✅ SOPS pour le chiffrement configuré
- ✅ Clés API (OpenAI, Supabase, ElevenLabs) configurées

#### Installation
```bash
# Cloner le repository
git clone https://github.com/dlsolutions/sentinel-zero.git
cd sentinel-zero

# Déployer automatiquement
./deploy.sh
```

#### Configuration
1. ✅ Déchiffrer les secrets : `sops -d .env.sops.yaml > .env`
2. ✅ Configurer les clés API dans le fichier .env
3. ✅ Redémarrer les services : `docker-compose restart`
