# NovaAgent AI – Business & Communication Intelligence

## Description

NovaAgent AI est un agent IA intelligent spécialisé dans la communication commerciale et la gestion des réseaux sociaux.

## Fonctionnalités

- Communication IA intelligente
- Analyse des réseaux sociaux
- Recommandations produits IA
- Analytics & Performance

## Installation

```bash
cd nova-ia-commercial
docker-compose up -d
```

## Accès

- Frontend: http://localhost:3001
- Backend: http://localhost:8001
- Documentation: http://localhost:8001/docs
